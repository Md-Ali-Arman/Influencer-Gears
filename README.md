# Influencer Products

A responsive product landing page built from a Figma design using HTML, CSS, and Tailwind CSS.

## Features

- Responsive design
- Figma-based UI implementation
- Hero section
- Marketplace section
- Popular Collection
- Featured Products
- Responsive Footer
- Clean and minimal layout

## Technologies

- HTML5
- CSS3
- Tailwind CSS
- Tailwind CLI
- Git & GitHub
